# 当前界面功能清单

这份清单对应现在的 GTK 播放器（`player.py` + `netease_api.py`），再加上已经定下来、要在 Qt Quick 迁移里补上的播放缓存。其余项按这里逐项对照，不另加功能，也不删掉已经能用的行为。

界面是浅色、单窗口。左侧导航，中间一页内容，底部固定播放条。关闭窗口只是隐藏，播放留在托盘。

## 1. 窗口和导航

- 默认约 1080×680。记住上次的位置和大小，下次打开恢复。
- 最小 860×560。列表再长也不能把窗口顶出屏幕，只能在页面内部滚动。已经撑出屏幕的尺寸，打开时收回工作区。
- 顶部：自绘红底音符、标题「网易云音乐（非官方）」、搜索框、账号按钮。
- 搜索框回车搜索歌曲和歌手。Ctrl+F 把焦点交给搜索框。
- 左侧导航宽约 196。悬停用浅蓝，不用和侧栏同色的灰。
- 固定入口：推荐、热歌榜、新歌榜、原创榜、飙升榜、私人 FM、听歌排行、我喜欢的音乐、每日推荐、下载管理。
- 「我喜欢的音乐」用原来的心形，不用歌单封面。其他自建歌单先显示默认图标，封面加载后再替换。
- 歌单封面和字号比主列表小一号。右侧有「刷新收藏」。
- 页面历史：从推荐进歌单、专辑、歌手后可以返回。Esc 先收播放列表浮层，再退出歌词、评论、下载页。

## 2. 账号

- 未登录显示「登录」。扫码登录，二维码只编码网易云登录地址。
- 登录后按钮显示昵称和会员类型（普通用户、音乐包、黑胶 VIP、黑胶 SVIP）。
- 菜单只有「退出登录」。退出删除本机 cookie，不上传。
- Cookie 只写在 `~/.local/share/netease-cloud-music/cookie`，目录 0700，文件 0600。不进仓库，不打印。

## 3. 推荐首页

- 推荐歌单封面网格。封面 120，名称和曲目数在下面。点击打开歌单。
- 榜单卡片：热歌榜、新歌榜、原创榜、飙升榜、说唱榜、ACG 榜。封面里已经有榜单名，不再叠一层字。
- 卡片比例约 148×78，避免 2:1 把封面文字压扁。点击打开对应榜单。
- 首页首次打开就要能点。不能等切过别的页面才响应。

## 4. 歌曲列表

- 列：序号、封面、歌名、VIP 标记、歌手、专辑、时长。
- 封面 36，先用占位，只给可见行加载。滚动后再补附近几行。缓存命中直接画，不重复请求。
- 双击一行播放，并把当前浏览列表设为播放列表。播放中的行用红色标记。
- 点击歌手名打开歌手页，点击专辑名打开专辑页。
- 右键：下一首播放、加入喜欢或取消喜欢、下载、查看评论、收藏到歌单。
- 正在浏览自己创建的歌单时，多一项「从当前歌单移除」。正在播放列表里的歌，多一项「从播放列表移除」。
- 歌手页和专辑页的歌曲列表使用同一套右键菜单。
- 歌单按页加载，先画出第一页，后一页接在后面，不把已经画出来的行清掉。
- 「我喜欢的音乐」按云端红心时间从新到旧排。

## 5. 歌手页和专辑页

- 歌手页：头像、名字、别名、歌曲数和专辑数、简介、专辑芯片、热门歌曲。
- 专辑芯片显示封面、名称、发行时间，点击进入专辑。
- 专辑页：封面、名称、歌手、简介、曲目。曲目在页面内部滚动，不撑高主窗口。
- 一首歌有多位歌手时，播放条上的歌手按钮弹出菜单再选。

## 6. 播放

- 底部播放条始终在。封面 46、歌名、歌手、喜欢、评论、收藏。
- 歌名打开歌词页。歌手打开歌手页。
- 控制：上一首、播放/暂停、下一首。播放图标 20 像素，深色自绘，白底和红底都看得见。
- 一点播放或切歌，图标立刻变成暂停。不要等管道真正出声再改图标。
- 切歌当下：停掉上一首，进度回到 0，时间改成新歌时长，歌词显示「加载中」，桌面歌词换成新歌名。新地址回来后再从新歌开头播。
- 进度条铺满播放条上方。点击或拖动任意位置跳转，暂停时和还没开播时也要停在点击处，不能弹回旧位置。
- 时间胶囊跟着滑块走。没变化时不重画。
- 播放模式：列表循环、列表播放、单曲循环、随机播放。
- 音质：标准、极高、无损、Hi-Res、高清臻音、臻音全景声、超清母带。菜单只显示这首歌服务端原样返回的档。勾选的是正在播放的档，不是偏好档。
- 臻音全景声请求立体声 FLAC。本机解不了的 Audio Vivid（av3a）不放进菜单。
- 切换音质后从当前进度继续。账号权限不够时降级，并在状态栏说明。
- 音量改的是本播放器的 PulseAudio 流，不改整机输出。还没出声时用上次记住的值。
- 播放地址只允许 `https`，主机是 `music.163.com`、`*.music.163.com` 或 `*.126.net`。本地文件只允许音乐目录里的真实文件，或下面的播放缓存目录。
- 正在播放的音频自动缓存到本机，再播同一首、同一音质时直接读缓存，不再拉流。
- 缓存目录是 `~/.cache/netease-cloud-music/playback/`，不进音乐库，也不进「网易云音乐」下载文件夹。用户手动下载的文件仍按现在的规则，优先于缓存。
- 缓存按歌曲 id 和实际播放档位分开。音质变了，或服务端降级后的档位变了，不拿另一档的文件冒充。
- 文件先写到临时名，整首下完再改成正式名。没下完的文件不拿来播放。
- 全部缓存文件加起来不超过 1GB。超了就删最久没播放的，直到回到 1GB 以内。正在播放的那首不删。
- 命中缓存时仍显示这首歌实际档位，不显示成「本地文件」。状态栏可以说明这次没有重新拉流。
- 退出登录不删缓存。缓存文件不进仓库，日志不打印缓存里的播放地址。
- 私人 FM 播到列表末尾自动再取一批。听歌排行是最近一周。
- 退出后再打开：恢复播放列表、当前歌曲、音质、播放模式和进度，但不自动开播。第一次点播放才从上次位置继续。

## 7. 播放列表浮层

- 嵌在主窗口右下角，不另开带标题栏的窗口。Wayland 下独立窗口不能定位。
- 显示当前播放列表、播放模式、正在播放的行。
- 双击跳播。右键和主列表同一套菜单。
- 点浮层外面收起。Esc 也收起。

## 8. 歌词

- 歌词页居中。当前句红色放大，相邻句深色，远处浅灰。有翻译时紧跟原文。
- 点击一行跳到该句时间。
- 时间戳按字头对齐，不提前半拍。
- 桌面歌词是单独的无边框窗口，主窗口留在 Wayland，才能跟上 1.75 倍缩放。
- 默认在任务栏上方居中。可拖动，松手记住位置。下次打开恢复位置。
- 悬停显示浅灰蒙版和淡红关闭按钮。没有双击关闭。
- 已唱的字淡蓝，未唱的字白色。接口没有逐字时间，按这一句的进度切。唱到这个字的开头就变色，最后一个字在切到下一句之前要能变色。
- 颜色在歌词窗口自己按时间往前走，不每拍读盘。
- 窗口高度锁成 64。退出播放器时关掉歌词窗口。上次开着，下次启动自动打开；上次关掉，下次不打开。

## 9. 评论和下载

- 评论只浏览。精彩评论和最新评论，带头像、昵称、时间和点赞数。可以翻页。不发送、不点赞。
- 下载使用加入队列时播放条上的音质，权限不够时和播放一样降级。
- 文件保存在音乐目录的「网易云音乐」文件夹。文件名不能跳出这个目录。
- MP3 写入标题和歌手。下次播放优先用本地文件。

## 10. 快捷键、托盘和状态

- 空格播放或暂停，左右方向键快进快退。
- 全局快捷键：Ctrl+Alt+P 播放或暂停，Ctrl+Alt+Home 上一首，Ctrl+Alt+End 下一首。没有全局快捷键服务的桌面跳过，不报致命错误。
- Ctrl+Q 退出。关闭窗口只隐藏，托盘左键打开，右键可以显示或退出。
- 状态栏显示正在获取的音质、实际档位、降级说明和错误。错误不带 cookie，不带完整播放地址。

## 明确不做

MV、社交动态、云盘、商城、发评论、点赞、绕过会员或付费限制。不使用官方唱片标志，图标继续用打包脚本生成的红底音符。
